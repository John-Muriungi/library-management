"# library-management"
#Features
Multi-Role Authentication System
Members: Borrow books, reserve tables, view available books

Librarians: Manage book borrowing, assign tables, and receive returned books

Administrators: Monitor all users, track reading activities, and view analytics

Core Functionality
Book Management: Browse, search, and filter available books

Borrowing System: Request, borrow, and return books with automatic fine calculation

Table Reservations: Reserve study tables with time slot management

Reading Tracker: Monitor which books users are currently reading

Real-time Updates: Live availability status for books and tables

Dashboard Features
Member Dashboard: View borrowed books, reservations, and due dates

Librarian Dashboard: Manage borrow requests, table assignments, and book returns

Admin Dashboard: View all users, monitor reading activities, and system analytics
